poc-android-convertemp
======================

Experimenting with Android SDK. This is a basic temperature converter that converts between Centigrade, Fahrenheit and Kelvin values.

[Google Play Store Page for Convertemp](https://play.google.com/store/apps/details?id=me.parambir.android.convertemp&hl=en)
